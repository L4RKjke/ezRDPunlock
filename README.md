# Betaflight FC: снятие защиты от чтения (DFU)

Утилита снимает защиту от чтения (RDP1 → RDP0) с полетного контроллера Betaflight на микроконтроллерах STM32 через загрузчик DFU. Также она может выполнить полное стирание памяти.

## Возможности

- Автоматический поиск платы по USB (VID:PID STM32 DFU или виртуальный COM-порт Betaflight).
- Перевод платы в режим DFU командой `bl` через CLI. Если автоматический переход не удался, программа предлагает перевести плату вручную.
- Два режима работы:
  - **Снятие защиты** (по умолчанию): снимает защиту от чтения. Основная Flash при этом стирается.
  - **Полное стирание памяти** (галочка в интерфейсе): выполняет mass erase. Если плата защищена, сначала снимается защита.
- После завершения операции программа ждёт отключения платы и переходит к поиску следующей платы.

## Требования

- Windows 10/11
- Python 3.10+ (для запуска из исходников)
- Драйвер WinUSB/libusb для DFU-устройства, если он не установлен автоматически
- Зависимости: `pyqt5` (или `pyqt6`), `pyserial`, `pyusb`, `libusb-package`

## Установка и запуск из исходников

1. Установите зависимости:
   `pip install -r requirements.txt`
2. Запустите `run.bat`. Он запускает скрипт и выводит лог операции.
3. Для графического интерфейса запустите приложение из папки проекта.

## Использование

1. Подключите полетный контроллер к ПК по USB.
2. При необходимости включите галочку **Полное стирание памяти**.
3. Нажмите кнопку запуска и дождитесь сообщения об окончании операции.
4. Отключите плату. Программа автоматически перейдёт к поиску следующей платы.

**Внимание:** обе операции стирают прошивку и настройки из основной Flash. После снятия защиты плату нужно заново прошить и настроить.

## Сборка

- Ручная сборка: `build.bat`. Результат появляется в папке `dist/`.
- Автоматическая сборка: GitHub Actions (`.github/workflows/build.yml`). Релиз создаётся только если в файле конфигурации `build_config.json` изменилась версия приложения. Версия и описание релиза берутся из этого же файла.

## Структура проекта

- `run.bat`: запуск скрипта из консоли
- `build.bat`: ручная сборка
- `build_config.json`: версия и описание релиза
- `styles.py`: стили интерфейса (тёмная тема)
- `.github/workflows/build.yml`: автоматическая сборка и релиз
